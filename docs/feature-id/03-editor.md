# 3. 에디터에서 쓰기

VS Code에서 기능 ID를 쉽게 다룰 수 있도록 TypeScript 플러그인(`packages/ts-feature-plugin`)을 두었습니다.

| 할 수 있는 것                | 방법                                             |
| ---------------------------- | ------------------------------------------------ |
| 기능 ID가 무슨 기능인지 보기 | `F-0154`에 마우스 올리기                         |
| 목록에서 골라 넣기           | `data-feature="`를 입력한 뒤 자동완성            |
| 표시 번호를 기능 ID로 바꾸기 | `"3.3.1"`을 쓰고 **Cmd + .** (Windows: Ctrl + .) |

에디터에서만 동작합니다. 빌드, `pnpm type-check`, CI에는 영향이 없습니다.

## 처음 한 번 설정

플러그인은 **레포에 설치된 TypeScript**를 쓸 때만 켜집니다. VS Code에 내장된 TypeScript는 레포의 플러그인을 읽지 않습니다.

1. `pnpm install`을 한 번 실행합니다.
2. 레포 루트의 `.vscode/settings.json`에 아래 내용을 추가합니다. 파일이 없으면 만듭니다. 이 파일은 gitignore되어 있어 각자 설정합니다.
   ```json
   {
     "typescript.tsdk": "apps/web/node_modules/typescript/lib",
     "typescript.enablePromptUseWorkspaceTsdk": true
   }
   ```
3. 아무 `.tsx` 파일을 엽니다.
4. 명령 팔레트(Cmd + Shift + P) → **TypeScript: Select TypeScript Version** → **Use Workspace Version**을 선택합니다.

### 켜졌는지 확인

`data-feature="F-0154"`에 마우스를 올렸을 때 아래처럼 보이면 성공입니다.

```
11.1.5 상단 바 (크리에이터 홈과 동일)
F-0154 · 소분류
```

아무것도 뜨지 않으면 [5. 문제 해결](./05-troubleshooting.md#마우스를-올려도-아무것도-안-떠요)을 보세요.

## 마우스 올려 보기

코드 어디서든 `'F-0000'` 꼴 문자열에 마우스를 올리면 표시 번호와 제목이 보입니다.
`data-feature` 값뿐 아니라 스크립트나 테스트 코드의 문자열에서도 동작합니다.

- 표시되는 번호와 제목은 레포의 기능 목록(`features.json`) 기준입니다. 팀웹과 다르면 [목록을 갱신](./04-workflow.md#기능-목록-갱신)하세요.
- 목록에 없는 ID라면 "features.json 에 없는 기능 ID"라고 나옵니다. 이 경우 타입 에러도 함께 납니다.

## 자동완성으로 골라 넣기

`data-feature="`까지 입력하면 소분류 기능 ID 목록이 뜹니다.
각 항목 옆에 표시 번호와 제목이 붙어 있고, 표시 번호 순서로 정렬됩니다.

```
F-0017   3.1.1 상품 랭킹 및 세부 정보 미리보기
F-0018   3.1.2 필터를 통해 카테고리 별 랭킹 확인
…
```

표시 번호나 제목 일부(`3.3`, `상단 탭`)를 입력해 목록을 걸러 볼 수도 있습니다.
VS Code 버전에 따라 이 거르기가 동작하지 않을 수 있습니다. 그럴 때는 아래 "표시 번호를 기능 ID로 바꾸기"를 쓰세요.

## 표시 번호를 기능 ID로 바꾸기

기능 ID가 기억나지 않으면 표시 번호를 그대로 씁니다.

```tsx
<TabBar data-feature="3.3.1" … />
```

타입 에러로 빨간 줄이 생깁니다. 그 줄에서 **Cmd + .** 를 누르면 수정안이 나옵니다.

```
F-0024 (3.3.1 상단의 상품 랭킹/ 크리에이터 신뢰도 랭킹을 클릭해 3.1 <-> 3.2 전환)로 바꾸기
```

선택하면 `"3.3.1"`이 `"F-0024"`로 바뀝니다.

- 배열(`data-feature={['3.1.1', 'F-0019']}`)에서도 동작합니다. 번호마다 수정안이 하나씩 나옵니다.
- **소분류 번호에서만** 동작합니다. `3.3` 같은 중분류나 목록에 없는 번호에는 수정안이 나오지 않습니다.
- 바꾸기 전에 수정안에 나온 제목이 의도한 기능이 맞는지 확인하세요. 레포의 기능 목록이 오래됐다면 예전 번호 기준으로 바뀔 수 있습니다.
