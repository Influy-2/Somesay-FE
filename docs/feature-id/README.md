# 기능 ID 안내서

팀웹(team.influy.com) 기능명세서의 기능과 프론트 코드를 잇는 방법을 설명합니다.
코드에 "이 화면 요소는 어떤 기능인지"를 표시해 두면, PR을 쓸 때 어떤 기능을 건드렸는지 자동으로 계산할 수 있습니다.

## 5분 요약

1. 기능에는 번호가 두 가지 있습니다. **코드에는 바뀌지 않는 기능 ID(`F-0024`)만** 씁니다.
   표시 번호(`3.3.1`)는 기획이 순서를 바꾸면 달라집니다.
2. 기능을 그리는 JSX 요소에 `data-feature` 속성을 답니다.
   ```tsx
   <TabBar data-feature="F-0024" tabs={…} />
   ```
3. 번호가 기억나지 않으면 `data-feature="3.3.1"`처럼 표시 번호를 쓰고 **Cmd + .** 를 누르면 기능 ID로 바뀝니다 (VS Code 설정 필요).
4. `F-0024`에 마우스를 올리면 `3.3.1 상단의 상품 랭킹/ 크리에이터 신뢰도 랭킹을 클릭해 3.1 <-> 3.2 전환`이 보입니다.
5. 기획의 기능 목록이 바뀌면 팀웹 JSON을 복사해 `pbpaste | pnpm --filter @somesay/shared features:update`를 실행합니다.
6. PR을 쓸 때는 `node apps/web/scripts/feature-impact.mjs origin/develop`으로 건드린 기능을 확인합니다.
